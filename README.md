# YM Player for Mac

Native macOS (SwiftUI + VLC) player for Xtream Codes IPTV — the Mac version of YM Player.

**Download:** the `.dmg` from the latest release. Drag YM Player to Applications.

The first time you open it macOS will block it (it isn't signed with a paid Apple developer
account): open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.
After that it opens normally.

Requires macOS 13 Ventura or newer, Apple Silicon or Intel.

Developed by Yousuf Miah.
